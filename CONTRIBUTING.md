Right now, the project isn't taking code contributions, but bug reports, feature requests, and plain feedback are all very welcome. This policy could change later.

Still want to help? Pick a program you already use, as long as a crash or miscompile would be no big deal and no important data is on the line. Good candidates: read-only document or media viewers, games and emulators, or small toy utilities. Build it with the LLVM backend (this means it should be roughly as performant as the original build), then tell us about anything odd you notice, whether that's bugs, crashes, or strange quirks the official build doesn't show. The issue tracker and Discussions tab is also open if you have feature suggestions or ideas for future development.

We use modern development tooling to fix bugs and improve compiler quality and capability. This includes IDEs, terminal editors plus their plugins, `clang-format`, address sanitizers, AI/LLM coding agents, compiler diagnostics, and debuggers, among other things. We're sharing this list partly to hand you some starting points for finding your way around a codebase this big and complex.
